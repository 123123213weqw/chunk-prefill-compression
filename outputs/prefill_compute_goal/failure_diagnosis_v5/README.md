# v5 失败样本的局部恢复诊断

**完成：108/108 个实验单元，约10分37秒；原始回答精确复现，原生/手动 identity gate、旧/新压缩引擎一致性、形状与源哈希审计均通过。**

对象是已看过答案的3个失败样本和3个正确对照，全部 narrative/16K。不是新验证集，也不是通用无损压缩证明。沿用 Qwen3-4B-Instruct-2507、RTX4080、FP16 SDPA、block1024、第30层64→16；只改变指定chunk的保留数。

## 主要结果

| 干预（其他chunk仍64→16） | 救回失败案例数 /3 |
|---|---:|
| 仓库证据chunk改为64→32 | 1 |
| 仓库证据chunk完全保留64→64 | 2 |
| 仓库和箱数两个证据chunk均64→64 | 2 |
| 对应的单个非证据chunk完全保留 | 0 |
| 对应的两个非证据chunk完全保留 | 1 |

- `1155f1c2b9ca39381f7f5844`：仅保留仓库chunk38即可恢复 Amber；keep32不足；所有已测placebo均未恢复。
- `18c5665358c364ff70111471`：保护仓库chunk38和箱数chunk204仍未恢复，输出依然 Dune。
- `3615d03937e9ef228782b28f`：仓库chunk37少压即可恢复；只保护箱数chunk204也可恢复；保护两个非证据chunk35/36同样恢复。不能把这个案例视为仓库原始证据局部独占的机制证据。
- 3个正确对照在所有已测干预下均保持正确。只有2个对照与失败样本同为Amber，第3个为Dune，不能当作完全匹配的随机对照。

## 说明了什么

局部保留可以影响错误，但“只保护原始证据所在chunk”不是充分条件。数据提示可能同时存在局部敏感性和分布式/全局上下文影响；本实验不分离均值混合、位置锚点、注意力归一化或浮点数值的各自贡献。未恢复不证明信息不可逆消失。

在原始v5全部 narrative/16K 中，Amber 的Full本就只答对5/8，压缩后为2/8；3个新增错误都集中在这个子组。不能把模型原有的实体检索弱点忽略不计。见 [历史分组分析](HISTORY_ANALYSIS.md)。

正确/错误答案的logP差来自固定紧凑JSON的teacher forcing；不是校准置信度，也不保证与自由生成的多行JSON胜负一致，不能把logP差的正负直接当作greedy正确性。保留原始分数仅用于诊断。
