# 真实模型 identity gate 发现的 mask/SDPA 差异

## 失败记录

`runs/4080-smoke-20260909-v0/`：冻结原版源码和 failed manifest 已保存。首样本某层缓存相对 RMS 为 0.0074114，超过预设 0.005；因此在任何压缩条件和性能测量之前停止。

这不是压缩算法失败：原版 identity 没有减少序列，但使用了与原生实现不同的 mask 传递策略。

## 根因线索与修正

从服务器安装的 Transformers 5.8.0 源码确认：

- HF SDPA mask 无 padding 且首次方形 causal prefill / 单 token decode 时可省略 mask。
- 非省略场景的 SDPA mask 是 boolean，True 表示可见。
- HF `use_gqa_in_sdpa` 依赖 attention_mask 是否为 None，改变 GQA 是否显式 repeat 的路径。

原版 layerwise 总是传显式 float additive mask，包括以上可省略场景。这在数学上表达相同可见性，但并不保证 FP16 后端执行路径与数值结果相同。

本次改动仅对齐 mask 策略（并显式限制支持 SDPA）：无历史或单 token 时传 None；其余传逻辑位置比较得到的 boolean mask。仍按 lower/upper family 各自实际 cache 长度构造可见性，不把变长 cache 重新填回全长。

没有放宽门槛，没有修改数据、模型、压缩深度或评分。

## 修正后的证据

`runs/4080-smoke-20260909-v1/identity_gates.json` 的 8 个 probe：

- cache 相对 RMS：0。
- 首次 logits 相对 RMS：0。
- KL：0。
- greedy token 序列：全部一致。

因此在这组真实 Qwen / FP16 / 4080 输入上，mask 策略对齐消除了已发现差异。没有单独分离 boolean dtype 与 mask 省略各自贡献，不声称只由其中某一项独立造成。

新增第 10 项回归测试：逐 attention 调用比较原生/identity 的 None 策略、mask dtype 与 mask tensor 内容。它补足此前仅在 FP32 小模型上比较数值未能揭示的问题。
